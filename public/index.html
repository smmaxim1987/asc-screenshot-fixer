ASC Screenshot Reset

Find and delete stuck screenshots in App Store Connect — the ones its own UI refuses to remove.

The problem what this tool is for

An interrupted screenshot upload — a dropped connection, a closed tab, a crash — leaves a red placeholder in Media Manager that spins forever:

  • Delete All is greyed out — App Store Connect refuses, thinking uploads are still running.
  • Dragging them away does nothing, and the slot cannot be reused.
  • Waiting does not help: they will never finish on their own.

Behind the red slots sit appScreenshot resources in terminal states (AWAITING_UPLOAD, FAILED, EXPIRED, MISSING_UPLOAD). The API can delete them, so this tool does — then you upload the real screenshot again.

Known App Store Connect issue, discussed on the Apple Developer Forums.

Where to get the data you only need to create the key once

  1. Open Users and Access → Integrations → App Store Connect API in App Store Connect (or the same section).
  2. Pick the Team Keys tab (a shared team key, recommended) or Individual Keys (a key tied to one person) and click +. Then choose a role — Developer is enough to delete screenshots, Admin is not required.
  3. Give the key a name (for example ScreenshotReset) and click Generate.
  4. Download the AuthKey_XXXXXXXXXX.p8 file immediately — Apple shows it once and cannot show it again. Store it somewhere safe: open -a TextEdit Downloads/AuthKey_XXXX.p8.
  5. Copy the Key ID and Issuer ID. The Issuer ID is shared by the whole team; every key has its own Key ID. Where to look: Team Key — Users and Access → Integrations → Team Keys. Individual Key — Users and Access → People, then your own profile → Individual API Key.
  6. Select the key type in the form below and paste the values. No Admin role needed — Developer is enough.
Where to find the Bundle ID (optional): App Store Connect → My Apps → pick the app → App Information → the Bundle ID row. You can skip it — the app will be picked from a dropdown instead.
Where to paste the private key: a .p8 file is plain text. Open it in a text editor, copy the entire contents including the -----BEGIN PRIVATE KEY----- and -----END PRIVATE KEY----- lines, and paste them into the field below. You can also just pick the file — the server reads it for you.

Credentials

The key is kept in server memory only and is never written to disk.

Scan

How to use it
  1. Pick an app and click Scan — every screenshot is listed by locale and display type.
  2. A red failed badge marks a stuck screenshot that needs deleting. A yellow processing one is fresh and usually clears itself within minutes. A green ready one works and must be left alone.
  3. Tick the ones you need, or click Select all stuck.
  4. Click Delete selected and confirm — this issues DELETE /v1/appScreenshots.
  5. Afterwards re-upload the images manually through App Store Connect: no backup of the files is made, only the asset in App Store Connect is removed.
